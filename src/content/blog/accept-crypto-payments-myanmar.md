ကရစ်ပတိုငွေဖြင့် ငွေပေးချေမှုကို မည်သို့လက်ခံမလဲ ဆိုသည့် အဖြေက ရိုးရှင်းပါသည်။ ပိုက်ဆံအိတ် လိပ်စာတစ်ခု၊ ငွေတောင်းခံ link တစ်ခု၊ အလယ်တွင် သင့်ပိုက်ဆံကို ကိုင်ထားမည့်သူ တစ်ဦးမျှ မရှိပါ။ လူအများက ဒါဟာ ကုမ္ပဏီအကောင့်ဖွင့်ရမယ်၊ ကိုယ်ရေးအချက်အလက် အတည်ပြုချက် (KYC) လုပ်ရမယ်၊ ရာခိုင်နှုန်း ကော်မရှင်ပေးရမယ်လို့ ထင်ကြသည်။ တကယ်တော့ မလိုပါ။ ပိုက်ဆံအိတ် လိပ်စာတစ်ခုနှင့်ပင် မိနစ်ပိုင်းအတွင်း တိုက်ရိုက် ကရစ်ပတိုငွေ လက်ခံနိုင်ပါသည်။

ဤလမ်းညွှန်သည် အရိုးရှင်းဆုံးနည်းဖြင့် ရှင်းပြထားသည်။ ဘာကြောင့် အလုပ်ဖြစ်သလဲ၊ **non-custodial** (ကိုယ်စားထိန်းသိမ်းမှုမရှိ) ဆိုတာ ဘာလဲ၊ တစ်ဆင့်ချင်း မည်သို့ စတင်မလဲ။ [Shieldz](https://shieldz.cash) ကို သုံးလျှင် ငွေသည် ကျွန်ုပ်တို့ဆီ လုံးဝ မဝင်ဘဲ တိုက်ရိုက် သင့်ပိုက်ဆံအိတ်ထဲ ရောက်သည်၊ ပလက်ဖောင်းအခ ၀ ဖြစ်ပြီး ကွန်ရက် (gas) အခကြေးငွေသာ ပေးရသည်။

## ဘာကြောင့် ကရစ်ပတိုငွေဖြင့် လက်ခံသင့်သလဲ

USDT သို့မဟုတ် USDC ကဲ့သို့ stablecoin (ဒေါ်လာနှင့် ၁:၁ ချိတ်ဆက်ထားသော) ဖြင့် ငွေပေးချေမှုသည် မိနစ်ပိုင်းအတွင်း ရောက်သည်၊ နယ်စပ်ကန့်သတ်ချက် မရှိ၊ သင်ညှိထားသည့် တိကျသော ပမာဏအတိအကျ ရသည်။ ဘဏ်လွှဲငွေနှင့် ကရက်ဒစ်ကတ်များသည် နယ်စပ်ဖြတ်ကျော် ငွေလွှဲရာတွင် နှေးကွေးပြီး ဈေးကြီးကာ တစ်ဆင့်ချင်း ကော်မရှင်ဖြတ်သည်။

## "non-custodial" ဆိုတာ ဘာလဲ၊ ဘာကြောင့် အရေးကြီးသလဲ

နည်းလမ်း နှစ်မျိုးရှိသည်၊ ကွာခြားချက်က ဒီနေရာမှာ ရှိသည်။

**Custodial (ကိုယ်စားထိန်းသိမ်း)။** ငွေပေးချေမှု gateway သည် ဖောက်သည်၏ ငွေကို သူ့ပိုက်ဆံအိတ်ထဲ ဦးစွာ လက်ခံပြီး၊ လက်ကျန်ကို သင့်ကိုယ်စား ကိုင်ထားကာ သူ့အချိန်ဇယားအတိုင်း သင့်ကို ပြန်ပေးသည်။ ငွေက သူ့လက်ထဲ ရှိသောကြောင့် စစ်ဆေးနိုင်၊ နှောင့်နှေးစေနိုင်၊ ရပ်ဆိုင်းနိုင်သည်။ ဒါကြောင့်ပင် KYC နှင့် အကောင့်ဖွင့်ခြင်း လိုအပ်လာသည်။

**Non-custodial (ကိုယ်စားထိန်းသိမ်းမှုမရှိ)။** gateway သည် သင့်ငွေကို လုံးဝ မထိပါ။ ဖောက်သည်သည် သင်ပိုင်ဆိုင်သော ပိုက်ဆံအိတ် လိပ်စာသို့ blockchain ပေါ်တွင် တိုက်ရိုက် ပေးချေသည်။ အလယ်တွင် ရပ်ဆိုင်းခံရနိုင်သည့် လက်ကျန် မရှိပါ။ [Shieldz](https://shieldz.cash) သည် ဤသို့ အလုပ်လုပ်ပြီး သင်ကိုယ်တိုင် [စစ်ဆေးနိုင်ပါသည်](https://shieldz.cash/verify)။

## အဆင့် သုံးဆင့်ဖြင့် စတင်ခြင်း

ကုဒ်ရေးစရာ မလို၊ အကောင့်ဖွင့်စရာ မလိုပါ။

1. **ပိုက်ဆံအိတ် လိပ်စာတစ်ခု ပြင်ဆင်ပါ။** `0x` ဖြင့် စသော EVM ပိုက်ဆံအိတ် (ဥပမာ Base ကွန်ရက်) မည်သည်မဆို ရသည်။ MetaMask, Trust Wallet အစရှိသည်။ သင့် private key ကို ဘယ်တော့မှ မပေးရပါ။
2. **ငွေတောင်းခံ link ဖန်တီးပါ။** [ငွေပေးချေမှု link generator](https://shieldz.cash/tools/payment-link) တွင် သင့်ပိုက်ဆံအိတ် လိပ်စာနှင့် ပမာဏကို ထည့်ပါ။ ရမည့်ငွေကြေး (ဥပမာ Base ပေါ်ရှိ USDT သို့မဟုတ် USDC) ကို ရွေးပါ။
3. **link ကို ဖောက်သည်ထံ ပို့ပါ။** ဖောက်သည်က link ကိုဖွင့်၊ သူ့ပိုက်ဆံအိတ်ဖြင့် ပေးချေ၊ ငွေက တိုက်ရိုက် သင့်ပိုက်ဆံအိတ်ထဲ ရောက်သည်။

## ဘယ် coin နဲ့ ရနိုင်သလဲ

ဖောက်သည်က သူ့လက်ထဲရှိ coin (BTC, ETH, USDT, USDC စသည်) ဖြင့် ပေးချေပြီး၊ သင်က ကြိုတင်ရွေးထားသော **coin တစ်မျိုးတည်း** ကို ရသည်၊ ဥပမာ Base ပေါ်ရှိ USDT။ အထူးသဖြင့် USDT ကို ကွန်ရက် ၇ ခုပေါ်တွင် ပေးချေနိုင်သည် (Tron/TRC20, Ethereum/ERC20, BSC, Polygon စသည်)၊ သင်ကိုယ်တိုင် Tron node လည်ပတ်စရာ မလိုပါ။ အင်္ဂလိပ်ဘာသာဖြင့် အသေးစိတ်ကို [how to accept USDT payments](/blog/how-to-accept-usdt-payments) တွင် ဖတ်နိုင်သည်။

## အခကြေးငွေနှင့် လုံခြုံရေး

အဓိကအချက်။ **ပလက်ဖောင်းအခ ၀**။ blockchain ၏ ကွန်ရက် (gas) အခသာ ပေးရသည်၊ Base ကဲ့သို့ ကွန်ရက်များတွင် ဆင့်အနည်းငယ်သာ ဖြစ်တတ်သည်။ non-custodial ဖြစ်သောကြောင့် ဖြတ်တောက်ခံရမည့် "ပလက်ဖောင်းလက်ကျန်" မရှိ။ blockchain ငွေပေးချေမှုများသည် အပြီးအပြတ်ဖြစ်၍ ကရက်ဒစ်ကတ်ကဲ့သို့ chargeback မရှိ။ ငွေလက်ခံလိပ်စာတိုင်းကို OFAC ပိတ်ဆို့စာရင်းနှင့် တိုက်စစ်သည်။

## စည်းမျဉ်းဆိုင်ရာ မှတ်ချက်

ကရစ်ပတိုငွေဆိုင်ရာ စည်းမျဉ်းများသည် နိုင်ငံအလိုက် များစွာ ကွာခြားသည်၊ အချိန်နှင့်အမျှ ပြောင်းလဲနိုင်သည်။ ဤဆောင်းပါးသည် ဥပဒေအကြံပြုချက် မဟုတ်ပါ။ သင့်ဒေသ၏ လက်ရှိ စည်းမျဉ်းများကို ကိုယ်တိုင် စစ်ဆေးရန်နှင့် လိုအပ်ပါက ကျွမ်းကျင်သူနှင့် တိုင်ပင်ရန် အကြံပြုပါသည်။

## မေးလေ့ရှိသော မေးခွန်းများ

**ကရစ်ပတိုငွေ လက်ခံရန် အကောင့်ဖွင့်ရမလား။**
မလိုပါ။ ပိုက်ဆံအိတ် လိပ်စာတစ်ခုသာ လိုသည်။ လိပ်စာထည့်၊ link ရယူ၊ ငွေလက်ခံ စတင်ပါ။ KYC မလို။

**ငွေက ဘယ်ကို ရောက်သလဲ။**
တိုက်ရိုက် သင်ထိန်းချုပ်သော ပိုက်ဆံအိတ်ထဲသို့။ Shieldz သည် non-custodial ဖြစ်၍ ငွေကို ဘယ်တော့မှ မကိုင်၊ ရပ်ဆိုင်း၍ မရ။

**ပလက်ဖောင်းအခ ဘယ်လောက်လဲ။**
ပလက်ဖောင်းအခ ၀။ blockchain ၏ gas အခသာ ပေးရသည်၊ Base တွင် များသောအားဖြင့် ဆင့်အနည်းငယ်။

**ဖောက်သည်က ဘယ် coin တွေ သုံးနိုင်သလဲ။**
BTC, ETH, USDC, USDT, BNB စသည်။ သင့်ပိုက်ဆံအိတ်ထဲ ရမည့် coin တစ်မျိုးကို သင်ရွေးသည်။
